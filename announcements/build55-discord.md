## Blockintosh 0.6.5 Beta · Build 55

You can now update or change Minecraft versions within an existing profile!

Open **Profiles → Minecraft version → Update or change version**. Your worlds,
settings, skins, packs, and account stay with that profile, and each profile
remembers its selected build.

Also in this update:

- **Your desktop wallpaper in the launcher**, following the display the window
  is on and the matching light or dark wallpaper variant.
- **A proper light appearance**, with light cards and rails, dark text, and green
  controls. Dark mode keeps its dark cards and mint controls.
- **Cleaner Activity**, with world-loading test controls hidden unless Advanced
  Freeze Diagnostics is enabled.
- **A stable app name: Blockintosh.app.** Older versioned copies rename
  themselves after updating and refresh matching Dock shortcuts.

**Back up important worlds before switching versions.** A world saved in a newer
Minecraft version may not work in an older one. Release and Preview keep
separate game data. Existing direct-launch shortcuts keep their chosen build;
recreate a shortcut after changing that choice.

**Get build 55:** use **Blockintosh → Check for Updates…**, or download it here:
https://github.com/multision/blockintosh-releases/releases/tag/v0.6.5-beta.55

For a manual install, extract **Blockintosh.app** and move it to Applications.
This is still **0.6.5-beta**; the bundled mcSoda runtime is unchanged. The existing
macOS requirements and Minecraft for Windows license requirement still apply.

Thanks to everyone testing and sending feedback!
