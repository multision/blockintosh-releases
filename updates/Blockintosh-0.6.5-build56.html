Blockintosh 0.6.5 Beta · Build 56

0.6.5-beta build 56 fixes runtime preparation failures caused by missing canonical hostnames.

Build 56 fixes a Wine initialization crash on Macs whose hostname resolves without a canonical name. Minecraft can finish runtime preparation without resetting the launcher or changing the Mac hostname.

What’s new in 0.6.5

Update or change Minecraft versions from Profiles while keeping the same worlds, settings, skins, packs, and account. Each profile remembers its selected build.

Minecraft updates install alongside existing shared builds and select the new version only after verification and runtime setup succeed. Back up before changing versions; newer worlds may not work in older Minecraft versions.

World-loading test controls in Activity are now hidden unless Advanced Freeze Diagnostics is enabled.

The launcher now mirrors the desktop wallpaper and its matching light or dark HEIC image on the current display. Light mode uses pale cards and rails with dark text; dark mode keeps dark cards and mint controls. Wallpaper contrast adapts for readability.

The app is now distributed as Blockintosh.app. Updated copies with an older versioned filename rename themselves safely and relaunch, refreshing matching Dock shortcuts. Existing Blockintosh.app copies are never overwritten.

Fixed Microsoft licensing requests failing when Microsoft issues the newer sign-in ticket format.

Licensing service refusals now show the HTTP status and service error instead of a generic response decoding error.

Includes build 53’s PlayStation controller support and the same bundled mcSoda runtime.

First public beta

Native macOS launcher with worlds, profiles, add-ons, Release and Preview builds, and Xbox sign-in.

The packaged app includes the mcSoda runtime and backend. Minecraft still comes from your own Microsoft account and license.

Launcher updates

This build connects to the Blockintosh update feed. Future downloads are signed and hosted separately from the launcher source.

Update checks are manual for now. Older builds without a feed need this first install done manually.

Before you jump in

Apple Silicon and Rosetta are required. The launcher needs macOS 15.0+, while gameplay needs macOS 26.4+ with bundled GPTK 4 or macOS 15.4+ with the optional GPTK 3 setup.

This is still a beta. Realms, Marketplace, sustained performance, and wider Mac compatibility are still being tested. Back up important worlds before testing a new build.
