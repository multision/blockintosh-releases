Blockintosh 0.6.6 Beta · Build 72

0.6.6-beta build 72: new ways to run the game, proper Mac editing shortcuts, and a bunch of launcher improvements since build 57.

What's new since build 57?

• FEX is now a runtime option alongside Rosetta, powered by the new Blockintosh Wine 1.0 runtime. Pick it in Settings → Runtime, then choose VKD3D or the experimental Mullion renderer. Each profile keeps its own settings for both runtimes.

• FEX gameplay can run on macOS 15 or later. Rosetta is still available with the existing GPTK and DXMT options, so you can stick with the setup that works for you.

• Spatial MetalFX upscaling is available on both FEX renderers. Choose Quality, Balanced or Performance to render at a lower resolution and upscale the picture. DLSS and spatial upscaling are kept separate so you dont accidentally stack them.

• FEX startup, fullscreen, mouse handling and display scaling have had a bunch of fixes. Fresh profiles can start without an existing game settings file, and starting Minecraft should open one game window instead of duplicate hosts.

a few things that should feel better

• The launcher now uses a snapshot of your actual desktop wallpaper, including animated wallpapers, instead of picking the wrong background. It keeps the blur, and macOS will ask for Screen Recording access the first time. You can switch to a plain background in Settings.

• Command-C/X/V/A/Z/Y now work for copy, cut, paste, select all, undo and redo in the Minecraft window. Control shortcuts still work too, with clipboard sharing between the game and your Mac.

• Managed profiles can now be permanently deleted. If you just want one out of the way, choose Keep archive instead so you can recover it later. Permanent deletion really does delete it, so keep a backup if youre unsure.

• You can choose 1, 4, 8 or 16 simultaneous Minecraft downloads. The default is 8; try a lower setting if your connection struggles.

• Downloads now give clearer errors for sign-in, licensing, missing files, storage space and folders the launcher cant write to, instead of leaving you guessing what went wrong.

• When getting the latest game, you can select Minecraft for Windows, the Java & Bedrock PC bundle, or a custom Store product ID. You still need a valid license. Bundle-owned accounts need more community testing.

graphics stuff to know before you jump in

• The new runtime lets you try experimental RTX and DLSS on VKD3D as well as Mullion. Theyre optional, still depend on the game and content youre using, and can cause problems in some worlds or packs. If loading hangs, turn them off and try again.

• Spatial MetalFX is still there if you want upscaling without game-side DLSS support. Weve also kept a fix for some loading hangs when using VKD3D.

requirements & beta notes

Apple silicon and macOS 15+ are required for the launcher and FEX gameplay. Rosetta gameplay needs macOS 26.4+ with bundled GPTK 4, or macOS 15.4+ with optional GPTK 3. You need your own Minecraft for Windows license; Minecraft isnt included.

Still a beta, still not notarized. Realms, Marketplace, bundle-owned licensing and the full range of Macs, game versions and graphics settings need more testing. Back up important worlds before changing builds or runtimes. Switching runtimes doesnt copy your worlds between their profiles.
