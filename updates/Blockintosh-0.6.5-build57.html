Blockintosh 0.6.5 Beta · Build 57

Bug fixes

• Fixed runtime preparation failing when the macOS home folder ends with a dot or space. Existing profiles and worlds stay in place.

• Fixed runaway crash output creating huge log files. Runtime logs are limited to 16 MiB, event logs to 1 MiB, and older inactive session logs are cleaned up.

• Fixed background runtime output keeping a finished launch connected to the launcher. Output continues draining safely after the main process exits.
