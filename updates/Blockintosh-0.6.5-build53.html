Blockintosh 0.6.5 Beta · Build 53

0.6.5-beta build 53: DualShock 4 and DualSense controller mapping through the bundled mcSoda runtime.

What’s new in 0.6.5

  • DualShock 4 and DualSense now use the bundled SDL Xbox-compatible controller mapping automatically, including Bluetooth and USB input.
  • Existing profiles receive the controller settings on their next launch. No separate controller mapper or mcSoda download is needed.
  • PlayStation buttons map to the Xbox controls Minecraft expects. The game may show Xbox button labels.

First public beta

  • Native macOS launcher with worlds, profiles, add-ons, Release and Preview builds, and Xbox sign-in.
  • The packaged app includes the mcSoda runtime and backend. Minecraft still comes from your own Microsoft account and license.

Launcher updates

  • This build connects to the Blockintosh update feed. Future downloads are signed and hosted separately from the launcher source.
  • Update checks are manual for now. Older builds without a feed need this first install done manually.

Before you jump in

  • Apple Silicon and Rosetta are required. The launcher needs macOS 15.0+, while gameplay needs macOS 26.4+ with bundled GPTK 4 or macOS 15.4+ with the optional GPTK 3 setup.
  • This is still a beta. Realms, Marketplace, sustained performance, and wider Mac compatibility are still being tested. Back up important worlds before testing a new build.
