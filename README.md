# Blockintosh releases

Minecraft Bedrock on your Mac.

This repo is for packaged Blockintosh downloads, release notes, and distribution materials. Launcher development happens separately.

Website and docs: https://blockintosh.multision.dev/

## Before you jump in

- Apple Silicon Mac and Rosetta.
- Launcher: macOS 15.0+.
- Gameplay: macOS 26.4+ with bundled GPTK 4, or macOS 15.4+ with the optional GPTK 3 setup.
- Your own Minecraft for Windows license. Minecraft is not included.

This is still a beta. Back up important worlds before testing a new build. Compatibility and distribution notes are included with each release.

Not an official Minecraft product. Not associated with Mojang, Microsoft, or Apple.
